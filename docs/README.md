# ProtoPilot documentation

ProtoPilot is a Next.js application for drafting electronics projects with an AI assistant. These pages describe the current implementation; [PROGRESS.md](../PROGRESS.md) records development history and [RESEARCH.md](../RESEARCH.md) holds earlier technical research.

| [Assistant](assistant.md) | AI tools, stream events, and chat behavior |
| [Project model](project-model.md) | Schema, compact plans, revisions, and electrical checks |
| [Privacy and hardware safety](privacy-and-safety.md) | Data flow, storage limits, and physical build limits |
| [Deployment](deployment.md) | Vercel configuration and release checks |
